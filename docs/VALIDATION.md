## ARM 의존성 수정

ONNX Runtime 1.30.0은 이번 Linux ARM64 에뮬레이터에서 import 시 segmentation fault가 발생했습니다.
1.22.1로 비교 검증한 뒤 Linux aarch64에서만 이 버전을 고정했습니다.
AMD64·Windows는 잠금 파일의 1.30.0을 사용합니다.

수정 후 ARM64 전체 45개 테스트 및 실제 E5 INT8 모델의 한국어 질문 추론이 통과했습니다.
실제 모델 출력은 384차원, 제곱 노름 0.99999994였습니다.
이는 Pi에서의 속도·메모리 실측이나 오류 원인이 모든 ARM 장비에 동일하다는 주장이 아닙니다.
의존성을 갱신할 때 ARM import와 추론 검증을 다시 수행해야 합니다.
